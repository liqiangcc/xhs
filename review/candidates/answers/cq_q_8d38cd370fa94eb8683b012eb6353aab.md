# 二叉树的前序遍历（Pre-order Traversal）

## 核心结论

前序遍历的访问顺序是 **根 → 左子树 → 右子树**。来源只给题名，没有固定语言、节点数量或 API；这里采用常见 Java 契约：`TreeNode` 只有 `int val`、`left`、`right`，`root == null` 返回空列表。面试手撕优先给迭代版：用栈保存待访问节点，弹出节点后先压右孩子、再压左孩子，这样 LIFO 会保证左子树先被处理；同时说明递归版就是按“根、左、右”直接展开。

## 1 分钟版

- 前序的唯一核心顺序是 `root -> left -> right`，访问节点时立即把值加入结果。
- 迭代版先把根入栈；每次弹出一个节点并记录，然后 **先压右、后压左**，因为栈后进先出，下一次会先访问左孩子。
- 空树直接返回空列表；只有一个节点时结果就是该节点。
- 每个节点只进栈、出栈一次，所以时间 O(n)；辅助栈最坏 O(h)，其中 h 是树高，退化树时 O(n)。

## 3 分钟版

推荐的迭代实现：

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

public final class Solution {
    public static final class TreeNode {
        int val;
        TreeNode left;
        TreeNode right;
        TreeNode(int val) { this.val = val; }
    }

    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) return result;

        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            result.add(node.val);
            if (node.right != null) stack.push(node.right);
            if (node.left != null) stack.push(node.left);
        }
        return result;
    }
}
```

递归版的语义更直接：对当前节点先记录 `val`，再递归左孩子，最后递归右孩子。它同样访问每个节点一次，但额外使用调用栈；树非常深时，迭代版更不容易遇到调用栈溢出。

## 关键细节

- **为什么先压右再压左**：栈是 LIFO；如果先压左再压右，右孩子会先弹出，顺序就变成根-右-左。
- **结果空间与辅助空间分开算**：返回列表本身需要 O(n)；若只讨论算法额外工作空间，显式栈是 O(h)，最坏 O(n)。
- **树高决定栈峰值**：平衡树 h≈O(log n)，极端单链树 h=O(n)。
- **空树是正常边界**：不应返回 `null`，而是空列表，更符合“遍历结果”的集合语义。
- **值是否重复不影响遍历**：遍历由节点结构决定，不依赖 BST 性质，也不需要去重。
- **不要误用队列**：普通 FIFO 队列得到的是层序遍历，不是前序 DFS。

## 原理机制

前序遍历可以看成一个 DFS 状态机：栈中的每个元素表示“这个节点的整棵子树还没开始处理”。弹出节点时先完成根节点动作，再把未来要处理的子树按逆序压栈。目标顺序是左后右，所以待办栈要先放右、再放左。这样每一轮都保持不变量：栈顶永远是按照前序顺序下一个应该访问的节点。递归实现只是把这个显式栈交给语言运行时的调用栈管理。

## 项目经验版

来源没有真实项目经历，不能虚构生产使用案例。工程映射上，前序适合“进入节点时就要做动作”的树结构处理，例如先处理父配置、再处理子配置；但真实场景是否使用递归，要看树深上界。若外部输入可能形成很深的树，显式栈通常更容易控制内存和失败边界。这是方案映射，不是来源事实。

## 常见追问

- 问：递归版怎么写？答：`if (node == null) return; visit(node); dfs(node.left); dfs(node.right);`，顺序本身就是前序定义。
- 问：为什么迭代版不是先压左？答：因为栈后进先出；为了让左孩子先弹出，必须让左孩子后入栈，所以先压右、再压左。
- 问：空间复杂度为什么有时写 O(h)、有时写 O(n)？答：显式栈与递归调用栈的峰值由树高 h 决定；h 最坏等于 n，所以最坏空间写 O(n)，平衡树则约 O(log n)。
- 问：能不能用 Morris 做 O(1) 额外空间？答：可以利用临时线索指针实现 Morris preorder，但会暂时修改树连接并恢复，代码和证明都更复杂；题干没有 O(1) 空间要求时，栈版更清晰。
- 问：前序和层序有什么最明显区别？答：前序是深度优先，处理完根后会继续深入左子树；层序用队列按深度从上到下逐层处理。

## 易错点

- 把访问顺序写成左-根-右，那是中序遍历。
- 迭代时先压左再压右，导致实际输出根-右-左。
- 空树返回 `null`，让调用方还要额外判空。
- 把二叉树误当 BST，使用节点值大小决定遍历方向。
- 只写递归代码却忽略深度可能接近 n 时的调用栈风险。
