# DFS 求二叉树所有子树中的最大平均值

## 核心结论

这题适合后序 DFS：每个节点只需要从左右孩子拿到“子树节点和 + 子树节点数”，就能在 O(1) 时间得到“以当前节点为根的整棵子树”的平均值，再与全局最优比较。原题只保存了“求二叉树中子树节点平均值的最大值，并要求 DFS”，没有保存返回 API、空树语义、节点值范围或并列规则。这里声明最小答案侧契约：节点值是 `int`；每个非空、以某个节点为根且包含其全部后代的树都算一个候选子树；返回最大平均值；空树非法；所有子树节点和必须能放进 `long`。

不要把最大值初始化为 0，因为整棵树可能全是负数。实现里保存当前最佳分数 `bestSum / bestCount`，用交叉乘法的 `BigInteger` 精确比较两个分数，最终才转成 `double` 返回。

## 1 分钟版

- DFS 定义：`dfs(node)` 返回这个节点整棵子树的 `(sum, count)`。
- 空孩子返回 `(0, 0)`；非空节点聚合为 `sum = left.sum + right.sum + node.val`，`count = left.count + right.count + 1`。
- 当前节点对应一个候选子树，平均值是 `sum / count`；和全局最优比较后更新。
- 必须后序，因为父节点要先拿到左右子树汇总结果。
- 全树只访问一次，所以时间 O(n)；递归栈 O(h)，退化树最坏 O(n)。
- 负数是重要边界：不能用 `0` 当初始最大平均值。

## 3 分钟版

```java
import java.math.BigInteger;

public final class MaxAverageSubtree {
    public static final class TreeNode {
        public final int val;
        public TreeNode left;
        public TreeNode right;
        public TreeNode(int val) { this.val = val; }
    }

    private static final class Stat {
        final long sum;
        final long count;
        Stat(long sum, long count) {
            this.sum = sum;
            this.count = count;
        }
    }

    private long bestSum;
    private long bestCount;
    private boolean hasBest;

    public double maxAverage(TreeNode root) {
        if (root == null) throw new IllegalArgumentException("root must be non-null");
        hasBest = false;
        dfs(root);
        return (double) bestSum / bestCount;
    }

    private Stat dfs(TreeNode node) {
        if (node == null) return new Stat(0L, 0L);

        Stat left = dfs(node.left);
        Stat right = dfs(node.right);
        long sum = Math.addExact(Math.addExact(left.sum, right.sum), node.val);
        long count = Math.addExact(Math.addExact(left.count, right.count), 1L);

        if (!hasBest || greater(sum, count, bestSum, bestCount)) {
            bestSum = sum;
            bestCount = count;
            hasBest = true;
        }
        return new Stat(sum, count);
    }

    private static boolean greater(long aSum, long aCount, long bSum, long bCount) {
        BigInteger left = BigInteger.valueOf(aSum).multiply(BigInteger.valueOf(bCount));
        BigInteger right = BigInteger.valueOf(bSum).multiply(BigInteger.valueOf(aCount));
        return left.compareTo(right) > 0;
    }
}
```

这里的 DFS 返回值不是“当前最优答案”，而是父节点继续计算所必需的局部统计量。全局最优则在每个非空节点完成聚合后检查一次；因此每个候选子树恰好比较一次。

## 关键细节

- **“子树”语义**：这里指以某个现有节点为根、包含该节点全部后代的完整 rooted subtree，不是任意连通节点集合。原题没有展开定义，因此必须把这一点说清。
- **负数**：例如根为 `-5`，两个叶子为 `-2`、`-8`，最大平均值是叶子 `-2`；若全局最大值从 0 开始，就会错误返回不存在的 0。
- **后序顺序**：必须先完成左右孩子统计，再计算当前节点的 `sum/count`。前序本身拿不到完整子树汇总，除非额外再遍历。
- **精确比较**：直接比较 `double` 对普通面试数据通常够用，但整数和/节点数本质是分数。这里用 `BigInteger` 做交叉乘法，避免 `long` 交叉乘法溢出和浮点近似改变最优选择。
- **求和溢出**：原题没有节点数和值域。示例用 `Math.addExact` 明确要求总和/count 放得进 `long`；若真实约束不能保证，应把汇总也升级成 `BigInteger`，而不是静默溢出。
- **并列**：题目只要求最大“值”，多个子树平均值相同不会影响返回。如果题目改成“返回对应根节点”，必须额外定义并列时选哪个。
- **递归深度**：时间 O(n)，递归空间 O(h)。极度退化的树可能栈溢出；若输入深度无界，应改成显式栈的后序 DFS。

## 原理机制

对任意节点 `u`，它的完整子树节点集合恰好由三部分不重不漏组成：左子树、右子树和 `u` 自身。因此只要左右 DFS 的 `(sum, count)` 正确，当前节点的统计量也必然正确。叶子节点自然得到 `(val, 1)`，所以这是一个直接的结构归纳。

同时，每个非空节点都唯一对应一个候选 rooted subtree。算法在该节点后序完成时比较一次 `sum/count`，因此不会漏候选，也不会重复扫描任何子树。若朴素地对每个节点重新遍历整棵子树求平均，链状树会退化到 O(n²)；一次后序汇总把重复工作消掉了。

## 项目经验版

来源是算法题，没有真实项目、数据规模或线上指标，因此不虚构项目经验。若工程中树可能非常深，我会优先把递归改成显式栈并用监控/压力样本验证最大深度；若节点值或规模可能使 `long` 溢出，则根据真实上界选择 `BigInteger` 或先证明数值安全。

## 常见追问

- 问：为什么必须 DFS？答：父节点的平均值依赖整棵左右子树的和与数量，后序 DFS 正好让孩子先返回这两个汇总量，再 O(1) 合并。
- 问：为什么不能每个节点重新求一次子树和？答：会重复访问后代；链状树中第 1 个节点扫 n 个、第 2 个扫 n-1 个，总代价 O(n²)。
- 问：全是负数怎么办？答：不要把 best 初始化为 0；第一次遇到的非空子树直接成为初始 best，之后做真实分数比较。
- 问：为什么用 `BigInteger` 比较，而 sum 还是 `long`？答：sum 的契约明确要求不溢出 `long`，但两个合法 `long` 再乘 count 仍可能溢出；`BigInteger` 只用于交叉乘法可保持比较精确。
- 问：如果要返回最大平均值子树的根呢？答：更新 best 时同步保存 `node` 即可，但要先补充“平均值并列时如何选”的契约。
- 问：递归会不会栈溢出？答：会，空间是 O(h)；输入可能退化成超深链时应用显式栈实现后序 DFS。

## 易错点

- 把“子树”误解为任意选一部分后代节点。
- 每个节点重新遍历后代，写成 O(n²)。
- 最大平均值初始化为 0，导致全负数失败。
- 用整数除法 `sum / count` 后再转 `double`，提前截断小数。
- 用 `aSum * bCount > bSum * aCount` 的 `long` 乘法却不考虑乘法溢出。
- 没有说明空树、数值范围或并列语义，却把某一种选择冒充成原题要求。
