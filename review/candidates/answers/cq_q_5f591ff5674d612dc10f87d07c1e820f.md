# 二叉树节点存储代价：到叶子节点的最大路径开销

## 核心结论

来源只给出“二叉树节点存储代价、到达叶子节点的最大路径开销”，没有固定 API。这里采用最小契约：每个节点有一个 `long cost`，路径必须从根走到真实叶子，答案包含根和叶子的节点代价；空树返回 0。后序 DFS 对每个节点返回“从该节点到某个叶子的最大累计代价”，总时间 O(n)，递归额外空间 O(h)。

## 1 分钟版

- 状态定义：`dfs(node)` = 从 `node` 出发、必须走到叶子的最大节点代价和。
- 叶子没有子树可选，直接返回自己的 `cost`。
- 只有一个孩子时必须走那个孩子，不能把缺失孩子当成代价 0；否则在负权场景会错误地“提前结束”。
- 两个孩子都存在时，返回 `node.cost + max(dfs(left), dfs(right))`。
- 每个节点只访问一次，O(n)；栈深等于树高 O(h)，最坏退化链为 O(n)。

## 3 分钟版

```java
public final class MaxRootToLeafCost {
    public static final class Node {
        final long cost;
        Node left;
        Node right;
        Node(long cost) { this.cost = cost; }
    }

    public static long maxCost(Node root) {
        return root == null ? 0L : dfs(root);
    }

    private static long dfs(Node node) {
        if (node.left == null && node.right == null) return node.cost;
        if (node.left == null) return node.cost + dfs(node.right);
        if (node.right == null) return node.cost + dfs(node.left);
        return node.cost + Math.max(dfs(node.left), dfs(node.right));
    }
}
```

这里特意没有写成 `node.cost + max(leftOrZero, rightOrZero)`。例如节点代价都是负数且只有一个真实孩子时，缺失分支的 0 不是一条“到叶子路径”；把它参与 `max` 会返回一条根本不存在的路径。

## 关键细节

- “路径”在本候选中严格要求终点是叶子；如果题目允许在任意节点停止，那是另一道最大前缀和问题。
- 使用 `long` 降低累计 `int` 溢出的风险；如果节点数和单节点代价连 `long` 都可能溢出，仍需由输入上界决定是否用更宽类型或显式溢出检测。
- 空树返回 0 是 API 选择，不是来源事实；若调用方要求空树报错，可把入口契约改成抛异常。
- 负代价不影响递推，只要缺失孩子不伪装成一条 0 代价路径。
- 复杂度：时间 O(n)，额外空间 O(h)；极深树若担心栈溢出，可用显式栈做后序遍历。

## 原理机制

子问题的边界由“必须到叶子”决定。一个内部节点的合法答案一定是“当前节点代价 + 某个真实孩子的合法根到叶答案”。两个孩子时只需选较大者；单孩子时没有选择权。因为每棵子树的返回值已经完整代表该子树最优合法路径，所以这个递推具备最优子结构，不需要枚举所有完整路径。

## 项目经验版

来源没有真实工程背景，不能虚构存储系统指标。若这种树表示目录、执行计划或资源层级，我会先确认“节点 cost 是独立开销还是累计值”“是否允许负数”“路径是否必须到叶子”和溢出上界，再决定递归、显式栈及数值类型。

## 常见追问

- 问：为什么单孩子不能用缺失分支 0 和它取 `max`？答：题目要求到达叶子，缺失孩子不是合法路径；负权时把 0 当候选会直接算错。
- 问：如果要求返回最大路径本身而不仅是代价？答：递推时同时记录选择的孩子，或返回“代价 + 路径/next 指针”，最后从根恢复路径。
- 问：如果路径可以从任意节点开始呢？答：状态和答案范围都会变化，不能复用“根到叶”契约；需要重新定义是否允许跨左右子树以及起终点条件。
- 问：树退化成链会怎样？答：时间仍 O(n)，但递归栈变成 O(n)，很深时应改显式栈避免调用栈溢出。

## 易错点

- 把题目偷偷改成“任意节点到任意节点”的二叉树最大路径和。
- 忘记根/叶代价是否计入，却直接套模板。
- 负权情况下把 null child 当 0 参与最大值。
- 用 `int` 累加但没有核对输入上界。
- 只说 O(n) 而忽略递归栈 O(h)。
