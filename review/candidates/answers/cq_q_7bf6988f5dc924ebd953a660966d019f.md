# 计算 Data 第一个维度的均值和方差

## 核心结论

原题只说“计算一个 Data 的均值和方差（第一个维度）”，没有保存 Data 的具体结构，也没有说明方差是总体方差还是样本方差。为了给出可执行实现，下面明确采用答案侧契约：`Data` 是非空、矩形、元素都为有限值的 `double[][]`；“第一个维度”解释为 axis 0，也就是跨行聚合，输出每一列的均值和**总体方差** `Σ(x-μ)²/N`。实现使用逐列 Welford 更新，一次扫描同时维护均值和平方差累计量，避免直接用 `E[x²]-E[x]²` 带来的额外消减误差。

## 1 分钟版

- 若数据形状是 `N × D`，沿 axis 0 聚合后输出两个长度为 D 的数组：每列均值、每列总体方差。
- 对第 r 行，当前样本数 `n=r+1`；每列执行 `delta=x-mean`、`mean += delta/n`、`m2 += delta*(x-mean)`。
- 扫描结束后 `variance = m2 / N`。如果面试官要样本方差，则在 `N>1` 时改成 `m2/(N-1)`。
- 本实现拒绝空矩阵、0 列、ragged 行和 NaN/Infinity，避免在题干没有缺失值语义时悄悄传播特殊值。
- 时间 O(ND)，额外空间 O(D)，不修改输入。

## 3 分钟版

```java
public final class Axis0Stats {
    public record Stats(double[] mean, double[] variance) {}

    public static Stats population(double[][] data) {
        if (data == null || data.length == 0) {
            throw new IllegalArgumentException("data must have at least one row");
        }
        if (data[0] == null || data[0].length == 0) {
            throw new IllegalArgumentException("data must have at least one column");
        }
        int rows = data.length;
        int cols = data[0].length;
        double[] mean = new double[cols];
        double[] m2 = new double[cols];

        for (int r = 0; r < rows; r++) {
            if (data[r] == null || data[r].length != cols) {
                throw new IllegalArgumentException("data must be rectangular");
            }
            int n = r + 1;
            for (int c = 0; c < cols; c++) {
                double x = data[r][c];
                if (!Double.isFinite(x)) {
                    throw new IllegalArgumentException("data must contain finite values");
                }
                double delta = x - mean[c];
                mean[c] += delta / n;
                double delta2 = x - mean[c];
                m2[c] += delta * delta2;
            }
        }

        double[] variance = new double[cols];
        for (int c = 0; c < cols; c++) {
            variance[c] = m2[c] / rows;
        }
        return new Stats(mean, variance);
    }
}
```

对 `[[1,2],[3,4],[5,6]]`，axis 0 上两列的均值是 `[3,4]`，总体方差都是 `8/3`。如果所谓“第一个维度”在面试官的框架里是别的轴，或者输入其实是一维向量/张量对象，应先按真实 API 重新确认维度语义。

## 关键细节

- **轴语义**：这里把第一维解释成行维/axis 0，结果保留剩余列维度；这是显式假设，不是题干已给事实。
- **总体 vs 样本方差**：当前除以 N；样本估计通常除以 N-1，N=1 时还要定义结果是否无定义/NaN/报错。
- **Welford 不变量**：处理 n 个样本后，`mean[c]` 是前 n 个值的均值，`m2[c]` 是它们相对当前均值的平方偏差和。
- **数值稳定性**：`sumSq/N - mean²` 在数值很大但方差很小时会做两个接近大数的相减；Welford 通常更稳健，但并不意味着浮点误差完全消失。
- **特殊值**：题干未说明 NaN、Infinity 或缺失值忽略规则，所以本契约选择拒绝，而不是默默跳过。
- **输入形状**：ragged 数组没有统一列数，无法定义固定长度的 axis-0 输出，因此直接报错。
- **复杂度**：每个元素只处理一次，时间 O(ND)；均值和 M2 各 D 个槽位，空间 O(D)。

## 原理机制

Welford 的关键是均值变化时同步修正平方偏差累计量。加入新值 x 后，旧均值是 μ，`delta=x-μ`，新均值 `μ'=μ+delta/n`；新样本对平方偏差和的增量可以写成 `delta*(x-μ')`。这样不需要先累计很大的平方和再减去均值平方，单次扫描就能得到均值和 M2。对二维数据，只要给每一列维护独立的 `(mean,m2)` 状态即可。

## 常见追问

- 问：为什么不是直接 `sum/N` 和 `sum(x*x)/N-mean*mean`？答：那种公式数学上成立，但浮点数下可能出现明显消减误差；Welford 避免直接相减两个接近的大量级值。
- 问：样本方差怎么改？答：M2 的更新不变，最终在 N>1 时用 `M2/(N-1)`；N=1 的语义需要额外约定。
- 问：axis 0 是什么意思？答：对 `N×D` 数据跨 N 行聚合，每个列位置独立统计，输出长度 D。
- 问：有 NaN 怎么办？答：当前契约直接拒绝；如果业务要忽略 NaN，需要按列维护有效计数，且不同列的分母可能不同。
- 问：可以并行吗？答：可以把数据分块计算 `(count,mean,M2)`，再用可合并统计公式归并各块；当前代码为了清晰只实现单线程扫描。

## 易错点

- 未确认维度语义就把“第一维”固定成某个框架的 axis 规则。
- 把总体方差和样本方差混为一谈。
- 用 `E[x²]-E[x]²` 却忽略高量级数据上的浮点消减。
- ragged 数据仍按第一行列数访问，导致越界或静默漏列。
- 题干没给 NaN 规则却擅自跳过，导致分母和结果语义不清。
