# LeetCode 287：寻找重复数

## 核心结论

仓库只保留题号与题名；按 LeetCode 287 当前官方题面，数组长度为 `n+1`、元素在 `[1,n]`，只有一个不同的重复值，要求不修改数组且只用常数额外空间。把 `i -> nums[i]` 看成函数图后，重复值对应从 `nums[0]` 出发路径的环入口，因此用 Floyd 快慢指针可在 O(n) 时间、O(1) 额外空间内返回它。

## 1 分钟版

- 值域 `[1,n]` 让数组值可以继续作为合法下标，数组天然形成单后继函数图。
- 重复值有多个前驱；从 `nums[0]` 出发会形成“链 + 环”，环入口就是重复值。
- 第一阶段 slow 走一步、fast 走两步直到环内相遇；第二阶段另一个指针回到 `nums[0]`，两者同速走，在入口再次相遇。
- 不改数组，只维护 3 个整数指针，所以时间 O(n)、额外空间 O(1)。

## 3 分钟版

```java
public final class Solution {
    public int findDuplicate(int[] nums) {
        int slow = nums[0];
        int fast = nums[0];
        do {
            slow = nums[slow];
            fast = nums[nums[fast]];
        } while (slow != fast);

        int finder = nums[0];
        while (finder != slow) {
            finder = nums[finder];
            slow = nums[slow];
        }
        return finder;
    }
}
```

官方约束保证每次下一跳都在合法范围内。第一阶段只保证找到环内相遇点；设起点到入口距离为 μ、环长为 λ，Floyd 相遇时的距离关系在模 λ 下成立，因此第二阶段让一个指针回到路径起点后，两者同速走会在入口汇合。

## 关键细节

- `HashSet` 能判重，但需要 O(n) 额外空间，不满足题目要求。
- 排序通常会修改原数组；复制后排序又需要 O(n) 额外空间。
- 重复值可以出现两次以上，`[3,3,3,3,3]` 也应返回 `3`。
- 返回的是重复“值”，不是某次重复出现的数组位置。
- 空数组、越界值或多个不同重复值超出 LeetCode 287 的输入契约，正式算法无需重新定义这些非法输入的结果。
- 两阶段总步数线性，额外状态只有 `slow/fast/finder`，所以 O(n) 时间、O(1) 额外空间。

## 原理机制

把位置当节点、`nums[i]` 当有向边。因为所有值都落在 `1..n`，从 `nums[0]` 开始会一直在有限节点集合里跳转并最终进入环。重复值 `d` 至少有两个不同前驱；在这道题的单重复值约束下，可达路径的合流点就是环入口。Floyd 利用快指针相对慢指针每轮多走一步保证环内相遇，再利用路径长度与环长的同余关系定位入口。

## 项目经验版

来源没有真实项目经历，不能虚构“线上使用 Floyd”。项目映射时只把它当成“受限单后继状态空间的环入口检测”技巧；一般业务判重更常见的是唯一索引、集合或排序，是否能套 Floyd 取决于是否真的存在可索引的单后继状态和同样的输入契约。

## 常见追问

- 问：为什么重复数一定存在？答：`n+1` 个元素只能取 `[1,n]` 的 `n` 个值，由抽屉原理至少有重复；官方题面进一步保证只有一个不同的重复值。
- 问：为什么环入口是重复值？答：重复值有多个前驱，函数图从起点的可达路径在这里合流并进入环；该题的单重复值约束把入口唯一绑定到这个值。
- 问：为什么第二阶段能定位入口？答：设链长 μ、环长 λ，第一阶段相遇时慢指针行程与 μ 的差是 λ 的整数倍意义下的同余；从起点和相遇点各走 μ 步会同时到入口。
- 问：二分计数可以吗？答：可以按值域统计 `<= mid` 的数量并用抽屉原理缩小区间，不修改数组且 O(1) 空间，但通常是 O(n log n)；Floyd 达到线性时间。
- 问：为什么不能简单用求和差？答：重复值允许出现两次以上，可能同时缺少多个值，简单的“数组和减去 1..n 的和”不能唯一推出重复值，还要面对整数溢出。

## 易错点

- 使用 `HashSet` 后仍把额外空间写成 O(1)。
- 默认重复值恰好只出现两次。
- 只背快慢指针代码，却解释不了数组为什么能映射成环、入口为什么等于重复值。
- 第二阶段随意从下标 0 开始而不保持同一函数图路径起点，也没有重新证明距离关系。
- 把题面契约外的非法输入处理当作本题必需逻辑。
