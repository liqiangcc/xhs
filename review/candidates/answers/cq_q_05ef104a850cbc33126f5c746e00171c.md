# 算法：最长回文子序列（LeetCode 516）

## 核心结论

用区间动态规划：令 `dp[i][j]` 表示 `s[i..j]` 的最长回文子序列长度。若两端字符相同，最优解可以同时取两端，转移为 `dp[i+1][j-1] + 2`；否则至少舍弃一端，取 `max(dp[i+1][j], dp[i][j-1])`。按 `i` 从右向左、`j` 从左向右填表，时间 `O(n^2)`、空间 `O(n^2)`。

## 1 分钟版

- 题目求的是**子序列**而不是子串：可以删除字符，但剩余字符相对顺序不能改变；LeetCode 516 的输入长度为 `1..1000`，字符为小写英文字母。
- 状态定义：`dp[i][j]` 是闭区间 `s[i..j]` 内最长回文子序列的长度，单字符区间 `dp[i][i]=1`。
- 若 `s[i]==s[j]`，两端可以作为同一回文的首尾，`dp[i][j]=dp[i+1][j-1]+2`；否则两端不能同时作为首尾，取去掉左端或右端后的较大值。
- 因为当前状态依赖 `i+1` 这一行和当前行更小的 `j`，所以 `i` 必须从大到小、`j` 从 `i+1` 到 `n-1`；最终答案是 `dp[0][n-1]`。

## 3 分钟版

这题最容易混淆的是“回文子序列”和“回文子串”。子串要求连续，而子序列只保序，所以不能用中心扩展直接求解。区间 DP 的不变量是：当计算 `dp[i][j]` 时，所有更短且会被它依赖的区间都已经有正确答案。

如果 `s[i]==s[j]`，可以把这两个相同字符放在某个 `s[i+1..j-1]` 最长回文子序列的两侧，因此得到 `dp[i+1][j-1]+2`；当区间长度为 2 时内部为空，结果就是 2。若 `s[i]!=s[j]`，任何回文子序列不可能同时把这两个不同字符作为首尾，因此最优答案一定包含在 `s[i+1..j]` 或 `s[i..j-1]` 中，取两者最大值即可。

```java
public final class LongestPalindromicSubsequence {
    private LongestPalindromicSubsequence() {}

    public static int longestPalindromeSubseq(String s) {
        if (s == null) {
            throw new IllegalArgumentException("s must not be null");
        }
        int n = s.length();
        if (n == 0) {
            return 0;
        }

        int[][] dp = new int[n][n];
        for (int i = n - 1; i >= 0; i--) {
            dp[i][i] = 1;
            for (int j = i + 1; j < n; j++) {
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = (j == i + 1) ? 2 : dp[i + 1][j - 1] + 2;
                } else {
                    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[0][n - 1];
    }
}
```

官方示例 `bbbab` 返回 4，`cbbd` 返回 2。实现还应覆盖单字符、全部不同、整个字符串已经回文、重复字符很多等边界。若题目严格遵循 LeetCode 516，输入不会是 `null` 或空串；上面的额外检查只是让独立方法在仓库测试中行为明确。

## 关键细节

- `dp[i][j]` 保存的是**长度**，不是具体序列；若面试官要求恢复一个实际的最长回文子序列，需要额外保存选择或根据 DP 表回溯。
- 填表顺序不能随意：`dp[i][j]` 依赖 `dp[i+1][j]`、`dp[i][j-1]` 和可能的 `dp[i+1][j-1]`，因此 `i` 逆序、`j` 正序最直接。
- `s[i]==s[j]` 时无需再与“丢左/丢右”取最大值；最长回文子序列的标准区间递推可直接把相同两端加入内部最优回文。
- 长度为 2 且两端相同的区间结果是 2；代码显式处理该边界，避免访问不存在的内部区间。
- 时间复杂度为 `O(n^2)`，二维表空间为 `O(n^2)`；对 `n<=1000`，状态数约一百万级。
- 可以把空间压缩到 `O(n)`，但必须谨慎保存上一轮的左上角状态；面试手写优先使用二维版本保证正确性和可解释性。
- 稳定算法事实可用可复现测试验证：官方示例之外，可对短字符串枚举所有子序列作为独立 oracle，与 DP 结果逐一对照。

## 原理机制

把问题拆成区间后，每个最优解都由两端字符的关系决定。两端相同意味着存在一个最优回文可以同时包含它们：先取内部区间的最长回文，再在首尾各加一个相同字符；两端不同则不可能同时成为同一回文的两端，至少要放弃一个端点，于是问题缩成两个长度更短的区间。所有转移都只依赖更短区间，因此形成无环依赖，可自底向上计算。

从证明角度看，基础状态 `dp[i][i]=1` 显然正确。假设所有长度小于 `L` 的区间都已正确：对长度为 `L` 的 `[i,j]`，若两端相同，内部最优回文加两端得到合法回文且达到该区间最优；若两端不同，任一合法回文至少不使用其中一个端点，因此必落在两个子区间之一。由此归纳得到 `dp[0][n-1]` 正确。

## 常见追问

- 问：最长回文子序列和最长回文子串有什么区别？答：子序列允许删除字符且只要求保序，子串必须连续；所以本题适合区间 DP，而最长回文子串常用中心扩展或连续区间 DP。
- 问：为什么两端字符相同时可以直接 `+2`？答：内部区间任一回文两侧加上相同字符仍是回文；同时，若一个最优解没有同时使用两端，可以通过区间 DP 的最优子结构证明不会优于包含这两个相同端点的构造。
- 问：如何把空间降到 `O(n)`？答：按 `i` 逆序更新一维 `dp[j]`，更新前保存旧的 `dp[j-1]` 作为二维表中的 `dp[i+1][j-1]`；遍历方向错了会覆盖仍需读取的状态。
- 问：如果要返回具体的回文序列而不是长度呢？答：保留二维 DP 表后从 `[0,n-1]` 回溯；两端相同且符合转移时同时收集两端，否则沿较大的子状态移动，最后拼接前后半段。
- 问：能否转成最长公共子序列？答：可以把 `s` 与其反转串做 LCS，复杂度同样是 `O(n^2)`；但直接区间 DP 更贴合“回文两端”的结构，解释和回溯通常更直观。

## 易错点

- 把“子序列”误当“子串”，错误要求字符连续。
- 只写转移方程却没有定义 `dp[i][j]` 的语义、基础状态和填表顺序。
- `i` 从小到大填二维表，导致读取尚未计算的 `dp[i+1][*]`。
- 忘记长度为 1/2 的边界，尤其在访问 `dp[i+1][j-1]` 时越界。
- 说空间已经是 `O(1)`；二维实现实际是 `O(n^2)`，一维压缩也仍是 `O(n)`。
- 声称返回的是具体最长回文序列；当前方法只返回长度，恢复序列需要回溯信息。
