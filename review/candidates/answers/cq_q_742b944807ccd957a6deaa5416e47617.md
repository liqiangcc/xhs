# 给定数组找众数及其众数中的中位数

## 核心结论

来源只保留“给定数组，找众数以及众数中的中位数”，没有说明并列众数、偶数个众数时中位数的定义、空输入行为和返回 API。这里显式采用一个最小可执行契约：数组元素按 `int` 处理；所有出现次数达到最大值的不同元素构成“众数集合”；把众数集合按数值升序排序后取中位数；若众数个数为偶数，则返回中间两个众数的算术平均值，因此中位数类型用 `double`；空数组或 `null` 直接拒绝。实现不修改输入。

## 1 分钟版

- 第一遍用 `HashMap<Integer,Integer>` 统计每个值的频次，同时维护最大频次 `maxFreq`。
- 第二遍把频次等于 `maxFreq` 的值收集到 `modes`，这些值就是并列众数。
- 将 `modes` 排序。奇数个众数时取 `modes[k/2]`；偶数个众数时取两个中间值的平均数。
- 偶数中位数相加时先转成 `long`，避免两个 `int` 先相加发生溢出。
- 复杂度是 O(n + k log k)，其中 `k` 是并列众数个数；额外空间 O(d)，`d` 是数组中的不同值个数。

## 3 分钟版

```java
import java.util.*;

static final class Result {
    final List<Integer> modes;
    final double median;

    Result(List<Integer> modes, double median) {
        this.modes = Collections.unmodifiableList(new ArrayList<>(modes));
        this.median = median;
    }
}

static Result solve(int[] nums) {
    if (nums == null || nums.length == 0) {
        throw new IllegalArgumentException("nums must not be null or empty");
    }

    Map<Integer, Integer> freq = new HashMap<>();
    int maxFreq = 0;
    for (int x : nums) {
        int f = freq.getOrDefault(x, 0) + 1;
        freq.put(x, f);
        if (f > maxFreq) {
            maxFreq = f;
        }
    }

    List<Integer> modes = new ArrayList<>();
    for (Map.Entry<Integer, Integer> e : freq.entrySet()) {
        if (e.getValue() == maxFreq) {
            modes.add(e.getKey());
        }
    }
    Collections.sort(modes);

    int k = modes.size();
    double median;
    if ((k & 1) == 1) {
        median = modes.get(k / 2);
    } else {
        median = ((long) modes.get(k / 2 - 1) + modes.get(k / 2)) / 2.0;
    }
    return new Result(modes, median);
}
```

例如 `[1,1,2,2,3]` 中最大频次是 2，众数集合是 `[1,2]`，按本答案显式采用的偶数中位数定义，中位数是 `1.5`。如果输入 `[3,1,2]`，三个值频次都为 1，因此众数集合是 `[1,2,3]`，中位数是 `2`。这两个行为属于本答案为了可执行而补充的契约，不应伪装成原题已明确给出的条件。

## 关键细节

- **先区分“一个众数”和“众数集合”**：存在频次并列时，不能只保留遍历中最后遇到的那个值，否则无法回答“众数中的中位数”。
- **中位数的对象是众数的值，不是频次**：先找出最大频次，再收集达到这个频次的值，然后才对这些值排序取中位数。
- **偶数个众数的语义要明确**：来源没有规定是取下中位数、上中位数还是两者平均。本答案选平均值，所以返回 `double`；如果面试官要求整数结果，必须按其口径调整。
- **整数溢出**：`Integer.MIN_VALUE` 和 `Integer.MAX_VALUE` 同时成为中间两个众数时，先按 `int` 相加可能溢出；先转 `long` 后再除以 `2.0` 可以避免这个问题。
- **不依赖 HashMap 遍历顺序**：众数收集后显式排序，所以结果与散列表迭代顺序无关。
- **空输入**：数学上空集合没有众数。本答案选择抛异常；如果业务需要返回空 Optional 或特殊值，应把接口契约改清楚。

## 原理机制

这道题可以拆成两个独立问题。第一步是“频次极值”：对每个不同元素计算频次，并找到最大频次。第二步是“极值集合上的顺序统计”：把所有达到最大频次的元素取出来，再在这些元素上求中位数。HashMap 负责把 O(n²) 的重复计数降为一次线性扫描；排序只发生在最多 `d` 个不同元素中的 `k` 个众数上，因此总复杂度为 O(n + k log k)。

如果数据范围极大且 `k` 也很大，可以进一步讨论无需完全排序的选择算法；但来源没有规模约束，先给出简单、可验证、边界清楚的实现更合适。

## 常见追问

- 问：为什么不能在统计频次时顺便只记一个众数？答：因为最大频次可能对应多个值，而题目还要求“众数中的中位数”，必须保留所有并列众数。
- 问：为什么要排序众数集合？答：中位数依赖有序位置；HashMap 本身不提供数值顺序。
- 问：偶数个众数怎么办？答：来源没规定。本答案显式采用两个中间众数的算术平均值；若面试官定义不同，算法主体不变，只改最后一步。
- 问：能做到 O(n) 吗？答：频次统计是 O(n)。如果要在不排序的情况下求众数集合中位数，可以对众数值使用线性选择算法，但实现复杂度更高；当前来源没有要求严格线性时间。
- 问：所有数字只出现一次怎么办？答：此时每个不同值都是众数，因为最大频次就是 1；中位数就是所有不同值排序后的中位数。
- 问：为什么偶数中位数先转 `long`？答：避免两个 `int` 中间值先相加造成溢出。

## 易错点

- 只保留一个最大频次元素，丢掉并列众数。
- 对“频次列表”求中位数，而不是对“众数值集合”求中位数。
- 依赖 HashMap 的遍历顺序直接取中间元素。
- 偶数个众数时没有声明返回规则，却直接整数除法截断。
- 两个 `int` 中间值先相加再转 `double`，导致极值输入发生溢出。
- 把空数组的行为、偶数中位数定义或 Java API 选择说成原题明确约束。
