# 二维空间中点到直线的距离（C++）

## 核心结论

仓库来源只保留“计算二维空间中点到直线的距离（C++实现）”，没有保存直线的输入表示、坐标范围或退化输入约定。这里明确采用一个可执行契约：用两个不同的点 `A`、`B` 表示一条无限直线，点 `P` 到直线的距离为平行四边形面积除以底边长度，即 `|cross(B-A, P-A)| / |B-A|`；若 `A == B`，它不能定义唯一直线，函数直接拒绝。

## 1 分钟版

- 设方向向量 `v = B - A`，从直线上一点到目标点的向量 `w = P - A`。
- 二维叉积绝对值 `|v.x * w.y - v.y * w.x|` 等于以 `v`、`w` 为邻边的平行四边形面积。
- 面积同时等于“底边长度 `|v|` × 高”，这个高就是点到无限直线的垂直距离。
- 因此 `distance = |cross(v,w)| / hypot(v.x,v.y)`，时间和额外空间都是 O(1)。
- `A == B` 时分母为 0，而且两个相同点不能确定一条直线；本答案把它定义为非法输入。
- 这是“点到无限直线”的距离，不是“点到线段”的距离；线段问题还需要判断投影是否落在线段内部。

## 3 分钟版

```cpp
#include <cmath>
#include <stdexcept>

struct Point {
    long double x;
    long double y;
};

long double pointToLineDistance(const Point& p, const Point& a, const Point& b) {
    const long double dx = b.x - a.x;
    const long double dy = b.y - a.y;
    const long double length = std::hypotl(dx, dy);
    if (length == 0.0L) {
        throw std::invalid_argument("line requires two distinct points");
    }

    const long double wx = p.x - a.x;
    const long double wy = p.y - a.y;
    const long double twiceArea = dx * wy - dy * wx;
    return std::fabs(twiceArea) / length;
}
```

例如直线经过 `(0,0)`、`(4,0)`，点是 `(1,3)`，叉积绝对值为 `12`，底边长度为 `4`，所以距离是 `3`。交换 `A`、`B` 只会让叉积变号，取绝对值后距离不变。

## 关键细节

- **来源边界**：仓库没有说明直线是 `Ax+By+C=0`、两点式还是点斜式；这里选择“两点确定无限直线”只是答案侧 API 契约。
- **不是线段距离**：无限直线允许垂足落在 `A-B` 延长线上；如果问题其实要求点到线段距离，需要先算投影参数并在端点距离与垂距之间分情况。
- **退化直线**：`A == B` 时方向向量长度为 0，不存在唯一直线。本实现抛 `std::invalid_argument`。
- **数值类型**：候选使用 `long double`、`std::hypotl` 和 `std::fabs`。来源没有保存精度要求；极端范围还要结合真实坐标约束定义误差策略。
- **非负性与方向无关**：叉积取绝对值，所以点在直线两侧得到相同距离；交换 `A`、`B` 也不会改变结果。
- **复杂度**：固定次数算术与平方根，时间 O(1)，额外空间 O(1)。

## 原理机制

二维向量叉积的绝对值表示两个向量张成的平行四边形面积。若把 `v=B-A` 作为底边，这个面积同时等于 `|v| * h`，其中 `h` 是 `P` 到直线 `AB` 的垂直高度，两边相除就得到距离公式。

也可以把两点式改写成一般式 `Ax + By + C = 0`，使用 `|A*x0 + B*y0 + C| / sqrt(A^2+B^2)`。两种写法本质相同；本候选用叉积形式，是因为两点输入时不必先构造一般式系数。

## 项目经验版

来源没有提供真实项目经历，不能虚构“自动驾驶线上就这样算”。工程落地时应先确认坐标系、单位、数值范围、直线还是线段、退化输入来源以及误差容忍，再用水平线、竖直线、斜线、在线点、端点交换、退化点和随机对照样例验证；这些是验证方法，不是原题保存下来的项目事实。

## 常见追问

- 问：为什么叉积除以底边长度就是距离？答：叉积绝对值是平行四边形面积，而面积等于底乘高；高就是点到直线的垂距。
- 问：如果直线给的是 `Ax+By+C=0` 呢？答：直接用 `|A*x0+B*y0+C| / sqrt(A^2+B^2)`，同时要求 `A`、`B` 不能同时为 0。
- 问：交换直线上的两个点会影响结果吗？答：只会让叉积变号，绝对值和底边长度不变，所以距离不变。
- 问：如果 `A==B` 怎么处理？答：两个相同点不能唯一确定直线；本候选显式抛异常。
- 问：点到线段怎么改？答：先计算点在 `AB` 上的投影参数；投影在线段内部时用垂距，投影在外部时取到最近端点的距离。

## 易错点

- 忘记对叉积取绝对值，导致直线两侧得到正负不同的“距离”。
- 分母写成方向向量长度平方；面积除以底边长度才是高度。
- 把点到无限直线和点到线段混为一谈。
- 不处理 `A==B`，直接除以 0。
- 题目没给输入表示、精度和异常约定，却把自己的函数签名说成原题要求。
- 用整数保存最终计算，导致除法截断或中间乘法溢出。
