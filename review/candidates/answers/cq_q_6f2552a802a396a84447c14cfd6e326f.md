# 算法：最长公共子串（DP）

## 核心结论

最长公共**子串**要求连续。最直接的 DP 定义是：`dp[i][j]` 表示 `a[i-1]` 与 `b[j-1]` 作为结尾时，最长公共子串的长度。若两个字符相等，当前连续段只能从左上角续上来，所以 `dp[i][j] = dp[i-1][j-1] + 1`；若不相等，连续性被打断，必须置 `0`。答案不是某一个固定终点，而是所有 `dp[i][j]` 的最大值。

这和“最长公共子序列”最容易混淆：子序列允许跳过字符，失配时会比较上方/左方；公共子串不允许跳过，失配就归零。

## 1 分钟版

- 状态要定义成“**以这两个位置结尾**的公共连续段长度”，这样连续性自然落在左上角依赖上。
- `a[i-1] == b[j-1]` 时，`dp = 左上角 + 1`；否则 `dp = 0`。
- 每个位置都可能是最长公共子串的结尾，所以遍历过程中维护全局最大值和在 `a` 中的结束位置。
- 二维表只依赖上一行左上角，可以压成一维；一维时 `j` 必须从右往左更新，否则 `dp[j-1]` 会被本轮覆盖。
- 时间复杂度 `O(mn)`；二维空间 `O(mn)`，压缩后空间 `O(n)`，通常让较短字符串作为第二维可进一步降低空间。

## 3 分钟版

设字符串长度分别为 `m`、`n`。定义：

`dp[i][j] = a[0..i-1] 与 b[0..j-1] 中，以 a[i-1]、b[j-1] 结尾的最长公共子串长度`。

转移只有两种：

- 若 `a[i-1] == b[j-1]`：`dp[i][j] = dp[i-1][j-1] + 1`；
- 否则：`dp[i][j] = 0`。

边界是第 0 行、第 0 列全为 0。遍历所有状态时维护 `best` 和 `endExclusive`，最终一个最长公共子串就是 `a.substring(endExclusive-best, endExclusive)`。如果存在多个同长度最优解，本实现返回扫描过程中首次达到该最大长度的一个；题源没有规定 tie-break，因此不额外编造“字典序最小”等规则。

```java
public final class LongestCommonSubstring {
    private LongestCommonSubstring() {}

    public record Result(int length, String substring) {}

    public static Result solve(String a, String b) {
        if (a == null || b == null) {
            throw new IllegalArgumentException("inputs must be non-null");
        }
        if (b.length() > a.length()) {
            Result swapped = solve(b, a);
            return new Result(swapped.length(), swapped.substring());
        }

        int[] dp = new int[b.length() + 1];
        int best = 0;
        int endExclusive = 0;
        for (int i = 1; i <= a.length(); i++) {
            for (int j = b.length(); j >= 1; j--) {
                if (a.charAt(i - 1) == b.charAt(j - 1)) {
                    dp[j] = dp[j - 1] + 1;
                    if (dp[j] > best) {
                        best = dp[j];
                        endExclusive = i;
                    }
                } else {
                    dp[j] = 0;
                }
            }
        }
        return new Result(best, a.substring(endExclusive - best, endExclusive));
    }
}
```

上面把较短字符串放在 DP 数组维度上，所以额外空间是 `O(min(m,n))`。交换两个输入不会改变最长长度；若题目要求返回“原始第一个字符串中的某个特定最优子串”，就不能在未定义 tie-break 时随意交换，需要固定扫描顺序并明确规则。

## 关键细节

- **为什么失配归零**：状态表示“以当前字符结尾的连续段”，当前字符一旦不同，就不存在长度大于 0 的公共连续后缀。
- **为什么不能取 `max(dp[i-1][j], dp[i][j-1])`**：那会允许跳过字符，求成最长公共子序列。
- **一维压缩方向**：`dp[j]` 新值需要上一行的 `dp[j-1]`；因此从右往左更新，保证左侧还是上一行旧值。
- **空串**：任一输入为空时循环不执行，返回长度 0 和空串。
- **重复字符**：例如 `aaaa` 与 `baaa`，连续状态会自然得到 3，不需要去重。
- **多个最优解**：题源没给返回规则；工程 API 若必须稳定返回某一个，应明确“第一个出现”“第二个字符串最早位置”或字典序等 tie-break。
- **字符语义**：示例使用 Java `char`，即 UTF-16 code unit。若题目把 Unicode code point 或用户感知字符当作一个字符，应先转换表示后再做同样的 DP，不能把 `char` 语义冒充成所有文本语义。

## 原理机制

这个 DP 的本质是枚举所有可能的“共同结尾”。任何公共子串都有一个在 `a` 中的结束位置和一个在 `b` 中的结束位置；若末尾字符相同，它去掉最后一个字符后一定对应左上角状态，因此转移没有遗漏。反过来，左上角已匹配的连续段加上当前相等字符仍然连续，所以转移也不会产生非法答案。对所有结尾取最大值，就覆盖了所有公共子串。

一维压缩只改变存储，不改变状态依赖。若从左往右更新，`dp[j-1]` 已经变成本行状态，相当于把同一行结果错误地接到当前字符上；从右往左可以保持“读取旧行、写入新行”的不变量。

## 项目经验版

仓库来源只保留算法题，没有真实业务输入规模、文本编码或线上性能数据，因此不虚构项目经历。实际使用时先确认字符串最大长度和字符语义：长度较小时 `O(mn)` DP 简单可靠；若文本非常长、需要大量重复查询或只求长度/匹配位置，才有理由评估 suffix automaton、suffix array 等更复杂方案，并用真实数据验证收益。

## 常见追问

- 问：最长公共子串和最长公共子序列差在哪？答：子串必须连续，所以失配时当前状态归零；子序列允许跳过字符，通常会从上方或左方状态取最大值。
- 问：为什么答案要取所有状态最大值？答：最长公共子串可能在任意两个位置结束，`dp[m][n]` 只代表恰好以两个字符串最后字符结尾的情况。
- 问：一维数组为什么倒序？答：当前 `dp[j]` 依赖上一行的 `dp[j-1]`；倒序能保证 `dp[j-1]` 在读取时还没被本轮覆盖。
- 问：能不能做到低于 `O(mn)`？答：可以针对更大规模考虑后缀自动机等结构，但复杂度、实现成本和字符集处理都会增加；题源只要求 DP，不应把另一套算法当作必需答案。
- 问：如果有多个同长度答案返回哪个？答：先看接口契约；题源没定义时只承诺返回任意一个最长公共子串，不额外假设 tie-break。
- 问：为什么不用滑动窗口？答：这里没有一个已知窗口长度，也没有单调条件能让普通双指针只向前移动就排除其它对齐；DP 正是在同时覆盖不同结束位置的匹配长度。

## 易错点

- 把“子串”写成“子序列”，失配时仍取上/左最大值。
- 只返回 `dp[m][n]`，漏掉在中间位置结束的最优解。
- 一维压缩时从左向右更新，读到本轮已覆盖的 `dp[j-1]`。
- 只记录最大长度，不保存结束位置，却又声称能返回具体子串。
- 没定义空串、null、多个最优解和字符编码边界。
