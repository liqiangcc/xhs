# 十进制字符串加法的可复核不变量推导

设两个合法输入从右向左依次为十进制位。第 `k` 轮开始时，`i`、`j` 指向各自尚未处理的最低位，`carry` 是已处理低位之和传入当前位的唯一进位；`reversed` 保存结果最低 `k` 位的逆序。

本轮把缺失位视为零，令 `sum = left + right + carry`。因 `left,right,carry` 分别处于 `[0,9]`、`[0,9]`、`[0,1]`，`sum` 在 `[0,19]`；`sum % 10` 是当前结果位，`sum / 10` 是传给下一高位的唯一进位。故一轮后不变量保持。

循环在两个下标均越界且 `carry == 0` 时终止；此时所有输入位和最终进位都已写入。反转得到完整和，裁剪前导零只改变表示、不改变数值，并将零统一表示为 `"0"`。每个输入字符仅验证和访问常数次，故时间与 builder/结果空间均为 `O(m+n)`。
