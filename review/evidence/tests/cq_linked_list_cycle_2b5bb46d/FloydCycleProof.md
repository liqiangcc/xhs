# Floyd 判环与入口定位的可复核推导

设从 `head` 可达的有限单链表由长度为 `μ` 的非环前缀和长度为 `λ >= 1` 的环组成；总可达节点数为 `n = μ + λ`。每轮循环后，`slow` 已走 `t` 步，`fast` 已走 `2t` 步。

## 无环

无环时可达节点数有限。`fast` 每轮至少前进两条 `next` 边；在至多 `ceil(n / 2)` 轮后，`fast == null` 或 `fast.next == null`。循环条件失败并返回 `false`，且不会访问空引用的 `next.next`。

## 有环

当 `t >= μ` 时，两个指针均已进入环。它们在环上的相对位移为 `(2t - μ) - (t - μ) = t (mod λ)`。令 `t` 为不小于 `μ` 的正整数倍 `λ`，则相对位移为零，二者相遇。这样的 `t` 不大于 `μ + λ = n`，所以有环时至多线性轮数返回 `true`。

循环体只保留 `slow` 与 `fast` 两个节点引用；不分配随输入长度增长的容器，也不改写 `next`，故辅助空间为 `O(1)`。

## 入口变体

若相遇发生在第 `t` 步，则上节的相遇条件给出 `t = 0 (mod λ)`。相遇点距入口的环内偏移为 `(t - μ) mod λ = -μ mod λ`。把一个指针放回 `head`，两个指针每次各走一步：走 `μ` 步后，第一个指针到入口，第二个指针的偏移变为 `(-μ + μ) mod λ = 0`，也到入口。

## HashSet 取舍

从 `head` 沿 `next` 逐个访问并把每个首次见到的节点引用加入集合：再次见到已有引用时判环；无环时到 `null`。最多保存 `n` 个可达节点引用，所以时间 `O(n)`、额外空间 `O(n)`；它比 Floyd 更直观，但不满足常见的常数额外空间要求。
