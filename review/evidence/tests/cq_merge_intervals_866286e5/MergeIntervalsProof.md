# 闭区间合并的可复核不变量推导

设输入包含 `n` 个满足 `start <= end` 的闭区间。先按 `start` 非降序排序。扫描中维护已输出的结果前缀和未输出的当前段 `[s,e]`。

不变量：在处理第 `i` 个排序后区间前，已输出前缀恰是所有已扫描区间中、与后续区间不可能相交的连通并集；当前段恰是已扫描但尚未输出的最右连通并集。

若下一个区间 `[a,b]` 满足 `a <= e`，它和当前闭区间共享至少一个点，二者并集仍是 `[s,max(e,b)]`，不变量保持。若 `a > e`，排序保证任意后续区间左端点也不小于 `a`，故没有后续区间能与 `[s,e]` 相交；输出它并以 `[a,b]` 开始新当前段后，不变量保持。扫描结束时输出最后当前段，得到且只得到输入的闭区间并集。

排序后扫描只访问每个区间常数次，为 `O(n)`；比较排序为 `O(n log n)`，所以总时间为 `O(n log n)`。候选实现分配排序副本和至多 `n` 个结果槽，额外空间为 `O(n)`。若题目改为半开区间 `[l,r)`，边界 `a == e` 不相交，应使用 `a < e`。
