## 关键细节

- JDK 8 的桶下标由扰动后的 hash 与 table 长度掩码计算。
- 链表长度达到 8 且数组容量至少 64 时才会树化，否则优先扩容。
- 默认负载因子 0.75 是空间与冲突概率的折中；扩容通常翻倍并重新分布节点。
- JDK 8 不再使用 Segment 分段锁作为主结构。
- 空桶初始化常用 CAS，非空桶更新在桶头上同步。
- size 是分散计数后汇总的近似瞬时值，不能把它当作跨操作事务边界。

## 原理机制

put 先计算 hash 和桶位置，再处理空桶、同 key 覆盖或冲突追加；扩容时利用旧容量对应的 hash 位把节点拆到原位置或原位置加旧容量。 节点和表引用的可见性由 volatile 保证；CAS 处理无竞争状态转换，发生桶冲突时缩小同步范围，扩容期间通过转移标记让其他线程协助迁移。
