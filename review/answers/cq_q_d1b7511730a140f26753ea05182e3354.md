## 原理机制

算法主线：队列中保存下一批待访问节点；每层开始时固定 size，循环 size 次即可保持层边界。 每一步都要保持该不变量，结束条件使它推出目标结果。 每个节点入队出队一次，时间 O(n)，空间 O(树最大宽度)。

Java 复习实现：

~~~java
static List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> ans = new ArrayList<>();
    if (root == null) return ans;
    Queue<TreeNode> q = new ArrayDeque<>(); q.add(root);
    while (!q.isEmpty()) {
        int size = q.size(); List<Integer> level = new ArrayList<>();
        while (size-- > 0) { TreeNode n = q.remove(); level.add(n.val);
            if (n.left != null) q.add(n.left); if (n.right != null) q.add(n.right); }
        ans.add(level);
    }
    return ans;
}
~~~
