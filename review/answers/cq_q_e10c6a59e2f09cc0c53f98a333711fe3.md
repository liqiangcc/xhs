## 原理机制

算法主线：小顶堆始终保存每条尚未耗尽链表的当前最小节点；弹出的节点是所有剩余节点中的全局最小值。 每一步都要保持该不变量，结束条件使它推出目标结果。 总节点数 N、链表数 K 时，时间 O(N log K)，堆空间 O(K)。

Java 复习实现：

~~~java
static ListNode mergeK(ListNode[] lists) {
    PriorityQueue<ListNode> pq = new PriorityQueue<>(Comparator.comparingInt(n -> n.val));
    for (ListNode n : lists) if (n != null) pq.add(n);
    ListNode dummy = new ListNode(), tail = dummy;
    while (!pq.isEmpty()) { ListNode n = pq.remove(); tail.next = n; tail = n;
        if (n.next != null) pq.add(n.next); }
    return dummy.next;
}
~~~
