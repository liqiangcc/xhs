## 原理机制

算法主线：结果尾指针 tail 之前始终有序，每次从两个当前候选中取较小者，最后接上未耗尽后缀。 每一步都要保持该不变量，结束条件使它推出目标结果。 两个输入总长度为 n 时，时间 O(n)；复用节点时额外空间 O(1)。

Java 复习实现：

~~~java
static ListNode merge(ListNode a, ListNode b) {
    ListNode dummy = new ListNode(), tail = dummy;
    while (a != null && b != null) {
        if (a.val <= b.val) { tail.next = a; a = a.next; }
        else { tail.next = b; b = b.next; }
        tail = tail.next;
    }
    tail.next = a != null ? a : b;
    return dummy.next;
}
~~~
