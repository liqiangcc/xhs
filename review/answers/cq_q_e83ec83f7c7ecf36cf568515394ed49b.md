## 原理机制

算法主线：求最大的 K 个时，小顶堆只保留已扫描元素中的 K 大候选，堆顶是候选边界；新值更大才替换。 每一步都要保持该不变量，结束条件使它推出目标结果。 时间 O(n log K)，堆空间 O(K)。

Java 复习实现：

~~~java
static int[] topK(int[] a,int k){
    if(k<0||k>a.length)throw new IllegalArgumentException();
    PriorityQueue<Integer> pq=new PriorityQueue<>();
    for(int x:a){if(pq.size()<k)pq.add(x);else if(k>0&&x>pq.peek()){pq.remove();pq.add(x);}}
    return pq.stream().mapToInt(Integer::intValue).toArray();
}
~~~
