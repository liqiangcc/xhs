## 关键细节

- 一级缓存通常是 SqlSession 级，二级缓存是 namespace 级且需显式评估一致性。
- 动态 SQL 应把值参数化，表名、排序列等结构只能从白名单生成。
- 批量、分页和 N+1 查询需要结合实际驱动与 SQL 观察。
- TLB 缓存地址转换，命中率影响内存访问成本。
- 缺页可能只是建立映射或从文件读取，不都意味着磁盘 swap。
- mmap、sendfile 等技术通过页映射或内核传输减少用户态复制。
- 先量化用户量、QPS、数据量、延迟与一致性目标。
- 再画核心读写链路和数据模型。
- 题目原文中的范围与版本是假设边界，信息不足时先澄清。
- 结论必须能由样例、日志、指标、源码或最小实验中的至少一种验证。

## 原理机制

代理 Mapper 生成 MappedStatement 调用 Executor，经 StatementHandler 参数化执行 JDBC，再由 ResultSetHandler 映射对象。 CPU 访问虚拟地址，经 TLB/页表翻译；映射缺失触发缺页异常，内核分配、载入或换入页面后恢复执行。
