## 关键细节

- Redis 常用 SET key value NX PX 建锁并用 Lua 校验 value 后删除。
- 看门狗续期不能消除长暂停、网络分区和资源端旧持有者写入风险。
- ZooKeeper 临时顺序节点可提供排队与会话失效语义，但仍需处理会话和业务副作用。

- 客户端缓存注册表能在控制面短暂故障时维持调用，但需处理陈旧实例。

## 原理机制

锁服务把所有权编码为唯一 token 和有效期；客户端只在持有期执行临界区，资源端可比较 fencing token 拒绝过期持有者。 提供方注册实例和元数据，消费方订阅并本地路由；控制面推送变化，数据面按负载策略选择实例并执行序列化与网络传输。
