# C++、Java、Python 的编译与执行模型有何差异？

## 核心结论

C++ 通常提前编译为目标机器码；Java 编译为字节码，由 JVM 解释并 JIT 热点编译；Python 常编译为字节码再由解释器执行。三者的执行与优化模型不能简化成纯编译/纯解释二分。

## 1 分钟版

- C++ AOT 优化充分、启动直接，但二进制与 ABI/平台绑定。
- Java 借 JVM 跨平台，JIT 可按运行时画像优化、去优化，代价是启动和预热。
- CPython 执行字节码并受动态类型和 GIL 等实现约束，其他 Python 实现可能不同。

## 3 分钟版

性能还受内存管理、运行时检查、库实现和工作负载影响。Java 可 AOT，C++ 也可动态编译扩展，Python 可调用原生库，答案要注明典型实现。 回答时先统一比较维度，再给选择条件与反例；定义本身不是终点，必须说明代价和不适用边界。

## 常见追问

- 问：Java 是编译还是解释？答：两者都有：javac 到字节码，JVM 可解释并 JIT 编译热点。
- 问：Python 是否完全不编译？答：不是，CPython 会生成字节码，但通常不提前生成本机机器码。
- 问：JIT 的代价？答：需要画像、编译 CPU/内存和预热时间，并可能发生去优化。
