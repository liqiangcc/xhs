# MySQL 常见索引类型及作用

## 核心结论

MySQL 索引可按物理组织分聚簇/二级，按约束分主键/唯一/普通，按列分单列/联合，另有全文和空间索引；“覆盖索引”是查询与索引列的关系，不是独立存储类型。

## 1 分钟版

- InnoDB 主键是聚簇组织，二级叶子存索引列和主键，查询非覆盖列需回表。
- 唯一索引除加速外还维护唯一约束，NULL 语义需按 MySQL 规则理解。
- 联合索引排序由列顺序决定，服务过滤、连接、排序和覆盖，但增加写放大。

## 常见追问

- 问：覆盖索引是什么？答：查询需要的列都能从当前索引取得，从而通常避免读取完整聚簇行。
- 问：索引越多越好吗？答：不是，会占空间、拖慢写入和统计维护，还可能干扰优化器选择。
- 问：联合索引顺序怎么定？答：综合等值/范围过滤、排序、选择性和复用，不能只按选择性口诀。
