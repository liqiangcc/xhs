# 零拷贝的原理与应用场景

## 核心结论

零拷贝不是完全没有复制，而是减少用户态/内核态之间的数据搬运和上下文切换；常见机制有 mmap、sendfile、splice 和 DMA，适用范围受文件、协议、加密和平台限制。

## 1 分钟版

- 传统文件发送常经历磁盘到页缓存、页缓存到用户缓冲、再到 socket 缓冲的复制。
- sendfile 让内核在文件和 socket 路径间传输，配合 DMA 可减少 CPU copy。
- mmap 把页缓存映射到用户空间，仍要处理缺页、生命周期和写一致性。

## 常见追问

- 问：零拷贝等于零次复制吗？答：不是，设备 DMA 等复制仍存在，重点是减少 CPU 和用户内核往返。
- 问：mmap 一定更快吗？答：不一定，小文件、随机访问、缺页和地址空间成本都可能抵消收益。
- 问：Kafka 为什么常提零拷贝？答：日志页缓存可直接通过 sendfile 类路径发往网络，减少用户态复制。
